# 📰 News Headline Reader with Text-to-Speech

## 📌 Project Overview

News Headline Reader is a web-based application that provides users with the latest news headlines and converts them into speech using Text-to-Speech technology. The application fetches real-time news from NewsAPI and allows users to listen to important updates, making news consumption easier and more accessible.

## 🎯 Problem Statement

People often find it difficult to stay updated with the latest news because reading multiple articles takes time. Additionally, visually impaired users and people who are multitasking may face challenges in accessing news content. This project provides a simple solution by displaying real-time headlines and converting them into audio.

## ✨ Features

- 🌐 Fetches real-time news headlines using NewsAPI
- 📰 Displays latest news based on selected categories
- 🔊 Converts news headlines into speech using Text-to-Speech
- 🔍 Allows users to select number of headlines
- 🎨 User-friendly and responsive web interface
- 🔗 Provides links to read complete news articles

## ⚙️ Project Workflow

1. User selects a news category and number of headlines.
2. The Flask application sends a request to NewsAPI.
3. NewsAPI returns the latest news data.
4. Headlines are displayed on the web page.
5. Text-to-Speech converts the headlines into audio.
6. Users can listen to the latest news updates.
